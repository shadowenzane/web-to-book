网页成书 · WebToBook v1.1.0
=========================

把网页（尤其是微信公众号文章）变成 EPUB 电子书、PDF 和 DOCX 文档。

【三端说明】
· macOS 版：网页成书.app —— 原生界面，PDF 用 WebKit 逐页排版，图片和文字不会被截断
· Windows 版：网页成书.exe —— 单文件，双击即用，无需安装 Python
· Android 版：网页成书.apk —— 手机/平板/电视盒子均可，文件保存到系统「下载」目录

【怎么用】
1. 粘贴网页链接（⌘V / Ctrl+V）；
2. 勾选要输出的格式（EPUB / PDF / DOCX，默认全选）；
3. 选择保存位置（默认「下载」）；
4. 点「开始转换」，等进度跑完即可。

【会自动做什么】
· 抓取网页，识别标题、作者、发布日期；
· 下载正文全部图片（原图最大分辨率，跳过微信装饰小图标）；
· 按加粗小标题自动分章，过短的“空标题”并入下一章；
· 生成三种文件并做结构校验（EPUB: mimetype/XML/清单/图片引用；DOCX: OOXML 结构）；
· 保存到本地。

【macOS 安装】
双击「网页成书.app」即可。首次打开若提示“无法验证开发者”，
右键 →「打开」→「打开」即可（本应用为本地 ad-hoc 签名）。
想放进「应用程序」文件夹，直接拖过去。

【Windows 安装】
双击「网页成书.exe」，单文件、无需安装 Python。
首次运行 Windows SmartScreen 可能提示，点「更多信息」→「仍要运行」。
该 exe 由 GitHub Actions（windows-latest）自动构建，可在仓库 Actions 页面下载最新 artifact。

【Android 安装】
1. 把 apk 拷到手机/电视，用文件管理器点击安装；
2. 或在电脑上：adb install -r 网页成书.apk；
3. 首次安装需允许「安装未知来源应用」；
4. 打开后粘贴链接，选择格式，点「开始转换」，文件保存到「下载」。

【已知限制】
· 仅支持可公开访问的页面；需要登录、已删除或触发平台验证的链接抓不到；
· 微信图片托管在 mmbiz.qpic.cn，个别图片可能因防盗链失败；
· 图片多的文章 PDF 页数偏多、体积偏大；
· Android 版为 v1.0 首发，兼容性仍在完善，遇到问题欢迎提 issue。
